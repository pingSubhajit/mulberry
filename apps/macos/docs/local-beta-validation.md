## Implementation

The Swift package remains the source of the app's modules. A generated Xcode app host now supplies automatic provisioning, the Mac push entitlement, the embedded profile, icons and sandbox signing. Development keeps its existing personal team and unrestricted entitlements; paid remote push is enabled for production beta. The same two environments as Android are crossed with debug/release compilation; beta is the temporary production bundle ID, not a third environment. Build products moved from `.build/app` to `.build/xcode/Build/Products/<configuration>` so building a replacement does not overwrite a running app.

Packaging copies only the native OAuth settings and API address from the selected client environment file. Installed apps no longer read a `.env` from the launch directory. Production HTTP requires the explicit local override and a loopback host. The build checks the Firebase bundle ID and refuses server credentials in its public plist. Local builds do not upload symbols.

The Mac explicitly registers APNs with Firebase Messaging and registers the resulting FCM token with the backend as `MACOS` / `prod`. The backend previously rejected MACOS despite listing it in its device contract; its validation and route type now use that contract. Shared Apple push registration keeps IOS as the default for existing callers and accepts MACOS explicitly. Account sign-out revokes push registration before clearing the session. Incoming messages fetch account or canvas state through the existing controllers; the notification delegate also retains the existing local partner welcome behavior. Advanced Settings shows the connection and last received/applied push revisions.
