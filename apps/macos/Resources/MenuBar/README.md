# Menu bar

`lock_screen_wallpaper.jpg` is the wallpaper of the menu bar's lock screen. It is the iPhone app's sign-in background, `apps/ios/Resources/Assets.xcassets/AuthBackground.imageset/auth_login_bg.jpg` (Mulberry's own artwork, with Squee), downscaled from 1080 × 2348 to 598 × 1300 for a 290-point screen at 2x.
