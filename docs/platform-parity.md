# Mulberry platform parity backlog

As of 2026-11-04.

We agreed to close 16 gaps between the apps: 13 need building on Android and 3 on iOS. Android and iOS show where each feature exists today.

| Feature | Description | Android | iOS |
| --- | --- | --- | --- |
| Account deletion | "Delete your account" in Settings, deleted immediately through `DELETE /me`. Google Play also needs a web deletion page. | No | Yes |
| Sign in with Apple | A second sign-in provider next to Google. | No | Yes |
| Link sign-in methods | Settings → Profile → Sign In lists Google and Apple, each linked (✓) or with a Link button. | No | Yes |
| Reactions button in toolbar | A heart button opens the six reactions, so the long-press isn't the only way in. | No | Yes |
| Reactions with any tool | Long-press opens the reaction arc with any tool selected. Slide onto a reaction and let go to send. Android needs no tool selected and only takes taps. | No | Yes |
| Drag to erase | Dragging the eraser removes every stroke it crosses. Android erases one tap at a time. | No | Yes |
| Clear disabled when empty | The Clear button greys out when the canvas is blank. | No | Yes |
| Eyedropper loupe | A magnifier floats above the finger while picking a colour. | No | Yes |
| First-drawing confetti | A one-time celebration for an account's first drawing. It's skipped if the same drawing levels up the streak. | No | Yes |
| Animated streak sheet | The count ticks up and today's day fills in. An unfinished today ripples, the bolt squishes when tapped, and the streak pill's number rolls. | No | Yes |
| Haptics | Feedback on sending and receiving reactions, colour, font and alignment picks, rotation snapping and the streak "today" moment. Android only has haptics in the streak-break film. | No | Yes |
| Accessibility depth | Spoken colour names, a spoken note when reactions arrive, layouts for large text sizes, and Reduce Motion on every screen. Android covers reduced motion on only a few screens. | Partial | Yes |
| Detailed sync status | Settings shows Connected, Connecting, Offline, Updating or Not paired. Android shows only Connected or Unpaired. | No | Yes |
| What's New | A sheet appears once per version, and Settings → What's new keeps the history with a red dot for unread notes. | Yes | No |
| Already-paired switch flow | Opening an invite while paired offers "Unpair & switch" or "Keep current pairing". iOS only shows a "You're already paired" alert. | Yes | No |
| Unpair from the confirmation sheet | A "Not {partner}? Unpair" link on the "You're paired" sheet. | Yes | No |
